pgrep -f "vivek" | grep -v "tmux" | xargs kill -9

Let's break down what this new command does:

pgrep -f "vivek": This finds the process IDs (PIDs) of all processes with "vivek" in their full command line. This is similar to your original command, but it only prints the PIDs, it doesn't kill anything yet.

grep -v "tmux": This part of the command is the key to solving your problem. It filters the list of PIDs from the previous step and removes any lines that contain the word "tmux". This ensures that the tmux sessions are safely ignored.

xargs kill -9: Finally, xargs takes the filtered list of PIDs and passes them as arguments to the kill -9 command, which forcefully terminates those specific processes.

=========================================================
🧾  BASH HISTORY COMMANDS — QUICK REFERENCE GUIDE
=========================================================

📘 PURPOSE:
-----------
This document explains how to view, clear, back up, edit, and restore 
your Bash command history in Ubuntu or any Linux terminal.

=========================================================
🔹 VIEW HISTORY
=========================================================

# Show all previously executed commands with line numbers
history

# Show only the last 20 commands
history 20

=========================================================
🔹 CLEAR CURRENT SESSION HISTORY
=========================================================

# Clear history for the current terminal session (temporary)
history -c

# Note: This clears only the in-memory history.
#       The saved file (~/.bash_history) is still kept.

=========================================================
🔹 CLEAR PERMANENT HISTORY
=========================================================

# Delete the saved Bash history file
rm ~/.bash_history

# Clear in-memory history as well
history -c

# Verify: open a new terminal and type 'history'
# It should now be empty.

=========================================================
🔹 BACK UP HISTORY TO A LOG FILE
=========================================================

# Save your full command history to a file (overwrite existing)
history > ~/command_history.log

# Append your current session history to the same file (no overwrite)
history >> ~/command_history.log

# Tip: Use this to archive commands before clearing them.

=========================================================
🔹 RESTORE HISTORY FROM A LOG FILE
=========================================================

# Copy the saved log file back to your Bash history
cp ~/command_history.log ~/.bash_history

# Reload updated history into memory
history -r

# Check: use 'history' again to confirm your new history is active.

=========================================================
🔹 EXTRA USEFUL COMMANDS
=========================================================

# Delete a specific entry by line number
history -d <number>

# Remove duplicates automatically
export HISTCONTROL=ignoredups:erasedups

# Prevent saving empty or repeated commands
export HISTIGNORE="&:[ ]*:exit"

# Disable saving history permanently (optional)
unset HISTFILE

=========================================================
✅ SUMMARY
=========================================================

| Action | Command |
|---------|----------|
| View history | history |
| Clear session | history -c |
| Delete saved history | rm ~/.bash_history |
| Backup history | history > ~/command_history.log |
| Append to backup | history >> ~/command_history.log |
| Restore history | cp ~/command_history.log ~/.bash_history |
| Reload new history | history -r |
